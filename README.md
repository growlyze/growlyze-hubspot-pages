# Growlyze HubSpot landing pages

- **HubSpot Implementation** (`growlyze-hubspot-implementation.html`): build a new HubSpot portal or fix an existing one, starting with a free health check.
- **HubSpot CRM Migration** (`growlyze-hubspot-migration.html`): move data and automations from Salesforce or another CRM into HubSpot.
- **HubSpot Onboarding** (`growlyze-hubspot-onboarding.html`): done-for-you HubSpot onboarding, live in as little as 3 weeks.

**Setup:** see [SETUP.md](SETUP.md). It's written so Claude can set everything up automatically: tell it *"understand SETUP.md and set it up"*. To run it yourself, use `npm start` and open http://localhost:8080.

> ⚠️ **`_originals-DO-NOT-USE/`** contains the original, unfixed source files, kept for reference only. Don't use, edit or deploy them.
